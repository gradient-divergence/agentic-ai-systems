# Autoencoders and NLP Representations: Exercise 6

Extend the dated policy index and check the new boundary questions.

From the companion root, select your Python submission:

```sh
AUTOENCODERS_NLP_SOLUTION="$PWD/exercises/autoencoders-nlp/starter.py" \
  python -m pytest exercises/autoencoders-nlp/test_acceptance.py -p no:cacheprovider
```

Set `AUTOENCODERS_NLP_SOLUTION` to another submission's path to check it. The public
reference solution is `reference.py`; select that path to check the reference.
The acceptance file checks the chapter's stated numerical and behavioral conditions;
a person must also read the submitted judgment where the exercise asks for one.
