# Typed Decision Models and Calibrated Decisions: Exercise 6

Fit on the permitted data, check the fixed negation probes and preserve the decision authority.

From the companion root, select your Python submission:

```sh
TYPED_DECISIONS_SOLUTION="$PWD/exercises/typed-decisions/starter.py" \
  python -m pytest exercises/typed-decisions/test_acceptance.py -p no:cacheprovider
```

Set `TYPED_DECISIONS_SOLUTION` to another submission's path to check it. The public
reference solution is `reference_solution.py`; select that path to check the reference.
The acceptance file checks the chapter's stated numerical and behavioral conditions;
a person must also read the submitted judgment where the exercise asks for one.
