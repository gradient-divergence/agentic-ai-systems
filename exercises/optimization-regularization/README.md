# Training Optimization and Regularization: Exercise 6

The printed decoupled update is supplied. Compare the three decay runs and justify your choice with training and validation losses.

From the companion root, select your Python submission:

```sh
TRAINING_CONTROL_SOLUTION="$PWD/exercises/optimization-regularization/starter.py" \
  python -m pytest exercises/optimization-regularization/test_acceptance.py -p no:cacheprovider
```

Set `TRAINING_CONTROL_SOLUTION` to another submission's path to check it. The public
reference solution is `demos/training_control_demo.py` from the companion root; select its absolute path to check the reference.
The acceptance file checks the chapter's stated numerical and behavioral conditions;
a person must also read the submitted judgment where the exercise asks for one.
