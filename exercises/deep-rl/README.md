# Deep RL exercises

`ppo-05.json` is generated by `python -m demos.deep_rl_demo --write-data`.
Its only planted implementation error is `clip(ratio) * advantage` without the
minimum. The four worked cases expose the missing pull back. Its batch samples
record their old probabilities, advantages, time weights and ratios after ten
epochs of that defective update; its false claim is part of the diagnosis.

For exercise 6, copy `starter.py` and implement `double_target`. Change the DQN
update to choose each next action with the online network and evaluate it with
the target network. Keep all other settings fixed, including the separate
behavior and replay random streams. Run the five training seeds under each
target, using the same ten evaluation episodes, and save a JSON report:

```json
{
  "training_seeds": [7, 11, 19, 23, 31],
  "evaluation_seeds": [1000000000, 1000000001, 1000000002, 1000000003, 1000000004,
                       1000000005, 1000000006, 1000000007, 1000000008, 1000000009],
  "settings": {"budget": 50000, "gamma": 0.99, "widths": [4, 64, 64, 2],
               "eta": 0.001, "batch_size": 64, "capacity": 20000,
               "refresh": 100, "epsilon_steps": 10000},
  "runs": [
    {"seed": 7, "original_returns": [], "double_returns": [],
     "original_starting_estimate": 0, "double_starting_estimate": 0}
  ]
}
```

The empty arrays and zero estimates above are placeholders. `original_returns`
and `double_returns` each hold ten undiscounted episode lengths: the task pays
one reward per push. Record the mean starting-state estimate of each network.
The checker discounts each length L as `(1 - gamma**L) / (1 - gamma)` using the
report's gamma (0.99 here), then compares the mean with the starting estimate
in `original_realized` and `double_realized`. It keeps undiscounted episode
lengths for the adoption comparison. Supply one row per
seed, the diff, the report and a second run with identical bytes. Record any
setting absent from the small schema, such as scaling, initialization, optimizer
constants, evaluation cadence and update cadence, beside the report.

```sh
PYTHONPATH="$PWD:$PWD/companion" OMP_NUM_THREADS=1 python companion/exercises/deep-rl/acceptance.py candidate.py report.json
PYTHONPATH="$PWD:$PWD/companion" OMP_NUM_THREADS=1 python -m pytest -p no:cacheprovider companion/tests/test_deep_rl.py
```

Apply the paired rule even if a selected seed looks better: five of five must
improve, and each seed's interval of episode-wise improvement must lie above
zero. Ten episodes give only a small-sample comparison; the chapter's normal
approximation is a teaching calculation, not a deployment guarantee.
