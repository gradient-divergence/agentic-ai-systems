# Delegated Model Building: Build

Compare random and surrogate-guided searches at the same 40-trial budget. Freeze July's open pool of 985 paid requests (2 to 31 July) before the search, freeze the selection before its single consultation, preserve earlier journal entries, and defend the resulting choice without promoting it.

Complete `build(directory, seed=7)` in `starter.py`. The result's evidence fields
are named in `test_acceptance.py`, which checks the chapter's printed acceptance
conditions. Keep the supplied data and earlier journals intact. A person also
reads the judgment or defense where the exercise asks for one.

From the companion root:

```sh
AUTOML_SELECTION_SOLUTION="$PWD/exercises/automl-and-selection/starter.py" \
  python -m pytest exercises/automl-and-selection/test_acceptance.py -p no:cacheprovider
```

Set `AUTOML_SELECTION_SOLUTION` to your submission's Python path. The public reference solution is
`reference_solution.py`; use that path to check it. Run it directly to print its
report. These constructed reruns grant no authority to pay or promote a change.
