# Generative Models and Simulation: Exercise 7

Extend the scenario vocabulary and reproduce the suite from its manifest.

From the companion root, select your Python submission:

```sh
GENERATIVE_MODELS_SOLUTION="$PWD/exercises/generative-models/starter.py" \
  python -m pytest exercises/generative-models/test_acceptance.py -p no:cacheprovider
```

Set `GENERATIVE_MODELS_SOLUTION` to another submission's path to check it. The public
reference solution is `reference.py`; select that path to check the reference.
The acceptance file checks the chapter's stated numerical and behavioral conditions;
a person must also read the submitted judgment where the exercise asks for one.
